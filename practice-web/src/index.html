识别范围与成熟陪练引擎

麦克风使用 Pitchy 单音检测，评分是 NoteLite 新增功能；持续同音需要短暂断开后重新起音。电脑键盘仅验证交互。MIDI 支持多音输入；当前评分涵盖音高、漏音与起音节奏，不评价触键、踏板、音色或时值。乐器名称来自谱面标注；名称推断不代表已通过该乐器的实录验收。

电子键盘完整陪练可在 NoteLite「书谱 → PianoBooster 陪练」中打开。多乐器商业识别引擎 PhonicScore / Practice Bird 需要厂商 SDK 授权，尚未接入。

复杂扫描谱可先用 ScanScore 等识谱软件导出 MusicXML，再从此页面导入；也可导入 MuseScore 校对后的乐谱。这是文件互通，外部识谱引擎未内嵌，NoteLite 不会自动购买或上传乐谱。

渲染采用 OpenSheetMusicDisplay，音频只在本机处理。开源组件与许可证
