# 音伴-你的音乐搭子 支持

音伴帮助你整理乐谱、识别扫描谱并练习 MusicXML。本 App Store iPhone / iPad 版本内置 Orpheus AI 识谱引擎，可在设备上将 PDF 和图片转换为 MusicXML 与 MIDI。

## 开始练习

1. 从“文件”导入 `.musicxml`、`.xml` 或 `.mxl` 乐谱。
2. 打开曲谱，进入练习，选择声部、小节与输入方式。
3. 使用麦克风或已连接的 MIDI 乐器演奏，结束后在“练习记录”中查看回顾。

MusicXML 可在本机练习，无需配置识谱服务器。麦克风适合单音旋律，不能可靠识别和弦或合奏；结果供练习参考，不评价音色、触键或踏板。MIDI 输入需要兼容并已连接的乐器。

没有现成乐谱时，可下载仓库提供的 [晨光练习曲 MusicXML 示例](https://raw.githubusercontent.com/Lucas0623z/NoteLite/main/practice-web/src/demo.musicxml)，将文件保存到“文件”后再导入。

## PDF 或图片如何识谱

1. 从“文件”导入 PDF、PNG、JPEG 或 TIFF。
2. 打开曲谱并点选“开始识别”。新任务在设备上处理，无需配置服务器或令牌。
3. 完成后打开生成的 MusicXML 练习，或通过系统分享导出 MusicXML / MIDI。如果识别结果包含多个部分，可以分别选择练习。

识谱期间请保持应用在前台。耗时取决于设备、页数和谱面复杂度。应用进入后台或你点选“停止识谱”后，会请求停止；当前图像处理会在安全结束后释放，之后可重新识别。识别结果需试听或校对后再用于练习。

### 为什么仍有“服务器设置”

该入口用于兼容以前创建的远端任务。已有任务仍使用原服务器查询、下载和清理；重新识别已有远端任务时，会先清理旧任务，再按当前设置重新上传。填写服务器地址不会将新导入曲谱切换为服务器识谱，本机识谱失败也不会自动上传。

不含本机引擎的其他客户端版本仍可使用 [桥接服务](../../bridge/README.md)。这类客户端需要可访问且具有有效证书的 HTTPS 地址和令牌。`localhost` 在手机上指手机本身。连接检查只确认服务可达，服务器任务请求才验证令牌。

## 常见问题

### 无法导入或进入练习

单份导入文件需小于或等于 25 MiB；进入练习的 MusicXML 或 MXL 文件还需满足 15 MiB 限制。本机识谱还会检查页数、图片尺寸及像素总量，过大的文件需要缩小或拆分后重新导入。加密 PDF 需先解锁。对于扫描谱，请先完成识别，确认已生成 MusicXML。识谱质量受原稿清晰度和谱面内容影响。

### 麦克风没有反应

在系统设置中允许音伴使用麦克风，检查输入设备，减少伴奏和环境噪声。音频中断或输入设备变化后，可重新开始练习。需要判断同时演奏的音符时，使用 MIDI 乐器更合适。

### 本机识谱失败

先查看曲谱详情中的错误提示。确认原稿可正常打开、图像清晰，并按提示解锁 PDF、缩小图片或拆分长文档。返回前台后可重新识别；不会自动切换到服务器。重新识别仍失败时，可提供不含敏感信息的样本和错误提示协助排查。

### 旧服务器任务上传中断或服务器不可达

检查 HTTPS 地址、证书、网络和令牌。返回应用前台后，已有任务会尝试恢复跟踪。未确认完成的上传需要手动重试，并可能在服务器产生另一项任务；有疑问时联系服务器运营者。

### 如何清理曲谱和服务器文件

删除曲谱会移除对应的本地原稿和结果。对于关联服务器任务的曲谱，详情还提供“清理服务器任务”，可保留已下载结果。删除这类曲谱时，应用先清理已有服务器任务；任务正在运行或无法连接时会保留本地记录。请等待任务结束或恢复连接后重试。暂停跟踪不会取消服务器任务。

本仓库桥接服务没有自动到期删除。独立备份、代理日志以及上传中断后未关联到本地记录的任务，需联系服务器运营者处理。练习历史、引擎配置和日志与曲谱单独保存，删除曲谱不会同时清空这些数据或异常遗留的引擎工作文件。详情见[隐私政策](privacy.md)。
