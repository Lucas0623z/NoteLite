## 描述

音伴-你的音乐搭子，把乐谱整理、离线识谱和日常练习放在一起。

【整理自己的乐谱】
从“文件”导入 PDF、PNG、JPEG、TIFF、MusicXML 或 MXL。原稿和识谱结果保存在设备上，方便预览与分享。

【在设备上识谱】
内置 Orpheus AI 识谱引擎，在 iPhone 和 iPad 上将 PDF 和乐谱图片转换为 MusicXML 与 MIDI。新导入的曲谱无需上传或配置服务器，识别完成后可继续练习或导出结果。

【逐音练习与回顾】
直接导入 MusicXML，或打开识别生成的乐谱，选择声部和小节，使用麦克风或已连接的 MIDI 乐器练习。通过音符和节奏反馈找到需要再练的地方，并在本机查看练习记录。包含多个部分的识谱结果可分别选择练习。

【按自己的节奏练习】
支持小节选择、试听、暂停继续、错音定位与重练。iPhone 和 iPad 界面随屏幕空间调整，便于在谱架旁使用。

使用说明：
• 识谱和 MusicXML 练习在本机进行。识谱时请保持应用在前台；耗时和结果会受设备、页数、谱面内容及原稿清晰度影响。识别后请先试听或校对。
• 麦克风适合单音旋律，不能可靠识别和弦或合奏。反馈供练习参考，不评价踏板、音色或触键。
• 单份导入文件上限为 25 MiB，进入练习的 MusicXML 或 MXL 文件上限为 15 MiB。
• “服务器设置”保留用于兼容已有远端任务；不会将新导入的曲谱切换为服务器识谱。

支持：https://github.com/Lucas0623z/NoteLite/issues

## App Review 审核说明草稿（仅审核信息字段）

This iPhone/iPad build includes the Orpheus AI recognition engine and its runtime, OCR, fonts, and model resources in the app. Newly imported PDF and image scores are processed on device and exported as MusicXML and MIDI. No account, login, server address, or token is required for this workflow. It does not download executable code or recognition models when recognition starts.

To test offline recognition:
1. Save a score PDF, PNG, JPEG, or TIFF in Files before disconnecting the network. A repository sample is available at https://raw.githubusercontent.com/Lucas0623z/NoteLite/main/data/examples/chula.png.
2. Open the app, tap “导入乐谱” (Import Score), and select the file. Open its detail screen and tap “开始识别” (Start Recognition).
3. Keep the app in the foreground while it processes the score. Duration varies with the device and score. The result is generated by the bundled engine. After completion, use the result links to share MusicXML/MIDI or tap “开始练习” (Start Practice). If several score parts were exported, choose one to practice.
4. If the app goes into the background or “停止识谱” (Stop Recognition) is selected, it requests cancellation at a safe processing boundary. Recognition can be started again; it does not automatically fall back to a server.

To test practice without running recognition, save https://raw.githubusercontent.com/Lucas0623z/NoteLite/main/practice-web/src/demo.musicxml to Files, import it, and tap Start Practice. In Practice Settings, select an instrument and input, listen to the selection, check “我已试听或校对乐谱” (I have listened to or checked the score), then start. Live performance input requires microphone permission or a compatible connected MIDI instrument. Microphone pitch analysis supports monophonic input and runs on device without saving or uploading audio. Practice summaries are stored locally.

Server Settings remains for compatibility with existing remote jobs. Such jobs can still query, download, retry, or request deletion from their configured server. Setting a server address does not send newly imported scores to that server in this build. The developer does not operate a recognition backend.

Privacy Policy and Support are available under Server Settings > Privacy and Support.

## 隐私申报依据（不复制到商店描述）

发布者已确认首版保持现有本地处理，数据收集属于未来计划；开发者不运营识谱服务器。当前客户端没有预设后端、账户体系、广告、行为分析或遥测。根据 Apple 对“收集”的定义，结合这一部署事实，`PrivacyInfo.xcprivacy` 的 `NSPrivacyCollectedDataTypes` 保持为空，`NSPrivacyTracking` 为 `false`。App Store Connect 可按当前版本填写 Data Not Collected（开发者及合作伙伴不收集本应用数据）。

本机识谱原稿及结果、麦克风声音、MIDI 输入、练习历史和引擎诊断信息只在设备上处理或保存。对于以前创建的远端任务，原稿重传、文件名、认证令牌和任务请求仍可能发送给用户独立配置的运营者；“检查服务器连接”也会访问填写的服务器。原文件不会自动脱敏。独立服务器不因用户填入地址而自动成为开发者的合作伙伴。具体行为和清理限制已在隐私政策中说明。

桥接服务的共享令牌用于认证，不是客户端创建的用户账户 ID。用户选择的服务器是否保留 IP 地址、认证信息和网关日志，需由对应运营者说明。支持联系通过外部邮件或 GitHub 页面进行，用户主动提交的信息按隐私政策处理。若未来由开发者或合作伙伴提供识谱服务、启用分析或其他数据收集，必须重新核对类别、关联状态、用途和留存政策，并在上线前更新清单、政策及商店申报。

`UserDefaults` 仅保存应用自身的服务器设置，使用必需理由 `CA92.1`。完整嵌入运行时还包含本机文件元数据访问和耗时测量；归档时应按实际 API 使用核对整个二进制及所有依赖的 required-reason 声明，并生成 Xcode Privacy Report。必需理由 API 的使用与离机数据收集是不同事项，不能仅由 Data Not Collected 推断隐私清单的 API 部分已经完整。
