# 音伴-你的音乐搭子 隐私政策

更新日期：2026 年 9 月 28 日

本政策适用于音伴的 iPhone、iPad 和 Mac 客户端。开发维护者为 Yuexuan Zhang（GitHub：Lucas0623z）。本 App Store iPhone / iPad 版本包含设备内识谱引擎，新导入的 PDF 和图片在本机处理。开发者不运营识谱服务器，也没有预设的数据收集后端。以前创建的服务器任务仍保留兼容功能；不含本机识谱引擎的其他客户端可使用独立服务器。具体行为如下。

## 设备上保存的内容

- **乐谱与任务**：导入的乐谱副本、生成或下载的结果、曲谱列表、原文件名、导入时间、任务标识、任务状态和已有任务的原服务器地址保存在应用存储中。
- **设置与凭据**：服务器地址保存在应用设置中。访问令牌按服务器分别保存在系统钥匙串中，仅在本设备解锁时供应用读取。
- **练习记录**：曲谱名称、练习时间、时长、完成情况、错音和节奏偏差等结果保存在本机，最多保留最近 500 次。

应用不提供账户或自有云同步。你使用的 iCloud、“文件”提供方、系统备份或设备管理服务，可能按照相应设置处理文件和应用数据，其行为由相应服务提供方管理。

## 本机识谱

本 App Store iPhone / iPad 版本使用随应用附带的 Audiveris 引擎及资源，在设备上处理新导入的 PDF、PNG、JPEG 和 TIFF，生成 MusicXML 和 MIDI。本机识谱不向开发者或识谱服务器发送原稿。填写服务器地址不会把新任务切换为服务器处理，本机识谱失败也不会触发自动上传。MusicXML 可直接在本机练习。

引擎可能在应用存储中保存配置、临时文件、运行日志、耗时和错误信息，用于本机处理与排错，不会自动发送给开发者。任务明确完成后会尝试清理对应工作文件；中断、超时或异常时可能保留部分输入或结果文件，以避免删除仍在使用的数据。

## 麦克风与 MIDI

选择麦克风输入时，应用会请求系统权限，将声音在本机实时分析为音高等练习信息。客户端不保存录音，不将声音或 MIDI 演奏输入发送到识谱服务器。练习结束或应用进入后台时会停止输入。你可以在系统设置中撤销麦克风权限，也可以使用已连接的 MIDI 乐器。

## 旧服务器任务及其他客户端的服务器功能

已有服务器任务的状态查询、结果下载和清理仍访问原服务器，发送任务标识及用于认证的访问令牌；文件下载还会发送对应结果文件名。重新识别已有远端任务时，应用会先清理旧任务，再按当前服务器设置通过 HTTPS 重新上传 PDF 或图片原稿及原文件名。不含本机识谱引擎的其他客户端，点选“开始识别”也会通过所配置的服务器处理新任务。服务器及其网络服务提供方可看到 IP 地址等网络连接信息。

原稿、文件名和图片元数据可能含有姓名、批注或其他个人信息，客户端不会在上传前自动去除这些内容。仅导入文件不会启动识谱上传；MusicXML 可直接在本机练习。

“检查服务器连接”访问所填地址的健康检查接口，不发送原稿或访问令牌。已有任务可能在应用回到前台后继续查询和下载，仍使用原服务器及其令牌。“暂停跟踪”停止客户端跟踪，不取消服务器正在执行的识谱。中断上传后，服务器可能已经接收了文件。

应用没有预设的开发者识谱服务器。客户端开发者不会因提供本应用而自动获得你自选服务器上的内容。你选择的运营者负责该服务器的访问控制、数据使用、日志、备份和保留政策。

## 保留与删除

- 删除曲谱会移除该曲谱的本地副本和生成或下载的结果。
- 曲谱关联服务器任务时，删除前会先请求清理该任务。任务仍在排队或运行、服务器不可访问或清理失败时，本地记录会保留并显示错误，待条件恢复后可重试。也可以在曲谱详情中单独清理服务器任务并保留已下载的本地结果。
- 删除曲谱不会同时清空独立保存的引擎配置、日志或异常遗留的工作文件；当前版本没有单独清空这些引擎数据的按钮。
- 本仓库提供的桥接服务默认保留原稿、结果、任务状态及引擎日志，直到清理完成，没有自动到期删除。其他服务器的保留时间可能不同。客户端清理无法确认运营者的独立备份和代理日志是否同时删除；请直接向该运营者提出相关请求。
- 删除曲谱不会同时删除练习历史；当前版本没有单独清空练习历史的按钮。
- 当前版本没有删除已保存钥匙串令牌的按钮。需要停用令牌时，请让服务器运营者撤销或更换令牌；不要依赖删除应用来撤销服务器凭据。
- 删除设备上的应用数据不会自动清理服务器、系统备份，或已导出、已分享的副本。请分别管理这些副本。

## 分享、支持与其他服务

使用系统分享功能时，所选文件会交给你选择的应用或服务。打开 GitHub 支持页面或发送支持邮件时，相应服务按其政策处理网络信息和你主动提交的内容。请勿在公开问题中提交访问令牌、私人乐谱或其他敏感信息。

客户端没有广告、行为分析或跨应用追踪功能，不出售用户数据。本机识谱、声音分析和谱面显示使用随应用附带的程序资源。自选识谱服务器的独立数据处理由其运营者负责。
