# AudiverisCore: first native porting slice

A Swift 5.9 package for iOS 16 and macOS 13, with no third-party dependencies.
It ports Audiveris adaptive/global binarization and whole-image foreground run
extraction. It does not yet detect symbols, assemble a score, or export MusicXML.

```swift
import AudiverisCore

let image = try GrayImage(width: width, height: height, pixels: grayscaleBytes)
let result = try AudiverisPreprocessor.preprocess(image)
// result.binaryImage.pixels: row-major, foreground 0, background 255
// result.horizontalRuns.sequences: rows of (start, length)
// result.verticalRuns.sequences: columns of (start, length)
```

Call this synchronous API from a worker task. The default cancellation hook
uses `Task.checkCancellation()`. A caller can supply a throwing
`cancellationCheck` closure; it is checked before allocation, every column/row,
and at least every 4096 pixels within a loop. Cancellation returns no partial
result.

`AudiverisPreprocessor.binarize` and `retrieveRuns` are available separately.
`PreprocessingConfiguration(method: .global(threshold: 140))` selects the global
filter. The default adaptive filter uses a half-window of 18 pixels and mean
and standard-deviation coefficients of 0.7 and 0.9. Foreground comparisons are
inclusive (`<=`), and variance uses Java's absolute-value semantics. Coefficients
must be finite and within the Java descriptor's range of 0 through 1.5.

## Resource bounds

The default input limits are 8192 pixels per dimension and 16 million pixels.
Adaptive filtering uses two circular integral tiles, each with
`(2 + 2 * halfWindowSize) * height` signed 64-bit entries. For the default
window, their combined allocation is `608 * height` bytes, independent of image
width. No full-image integral tables are allocated. The default integral memory
limit is 32 MiB.

`preprocess` caps the combined horizontal and vertical run count at two million
(32 MB of run payload on 64-bit platforms, excluding array capacity/overhead).
`retrieveRuns` applies that cap to its single returned table. Highly noisy images
can exceed this limit and fail explicitly. Dimension multiplication, integral
allocation arithmetic, and accumulator bounds are checked before processing.
Limits can be configured; callers should retain device-appropriate caps.

## Validation

From this directory:

```sh
swift test
swift test -c release
swift run -c release audiveris-core-benchmark
```

Tests cover clipped windows, circular-buffer wrapping, threshold equality,
one-pixel/one-row/one-column inputs, run endpoints/orientations, reconstructed
pixel invariants, cancellation, resource limits, and overflow rejection.
Nineteen committed oracle fixtures were generated by executing the original
Java filters/run extraction, including a bundled scanned-score image. Tests
compare every binary pixel and foreground run against those outputs.

The benchmark preprocesses a synthetic 2480 × 3508 staff raster. Its JSON output
reports elapsed time, run counts, and buffer payload estimates. It does not
measure note-recognition accuracy, peak process memory, or iPhone performance.
